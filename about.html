About CineVoyage

CineVoyage is a movie exploration website created as a Web Designing and Web Technologies project. The website provides a simple and attractive platform for users to explore movies and discover important information about their favourite films.

Users can browse the movie catalogue, view movie posters, and select a particular movie to explore its detailed information. CineVoyage is designed with a focus on simple navigation, organized content, and an attractive cinematic appearance.

The project demonstrates the use of HTML and CSS to create multiple connected web pages and a user-friendly movie portal.


📽️ Movie Catalouge

Explore a collection of movies with posters, titles, ratings, genres and other information.

⭐ Movie Details

Click on a movie poster to open a separate page containing detailed information about that movie.

📱 Responsive Design

The website layout can adjust to different screen sizes using responsive CSS techniques.
